# bin

Inventario inicial de binarios y scripts aportados para construir `iasi-setup-ecosystem`.

En esta fase se conserva deliberadamente el conjunto completo recibido. La réplica de instalación determinará qué elementos son:

- necesarios para instalar el ecosistema;
- necesarios para operar el ecosistema después de instalarlo;
- herramientas exclusivamente de desarrollo que deben salir de la distribución final.
