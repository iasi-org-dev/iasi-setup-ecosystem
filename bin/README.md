# bin

Initial inventory of binaries and scripts supplied to assemble `iasi-setup-ecosystem`.

The complete received set is intentionally preserved during the integration phase. The clean-install reproduction will determine which elements are:

- required to install the ecosystem;
- required to operate the ecosystem after installation;
- development-only tools that must not remain in the final distribution.
